# SELP
A Simple and Easy Language Parser made for Haxe

# WIP
This library is being worked on but for now it intends to support:
- A custom format called ```.selp```
- Easily fetching ```.selp``` from URLs
- Parsing ```.cvs``` and ```.tsv``` files from those that prefer it
- A **single-pass** quick parser
- **Regex** and automatic replacing of **patterns** (e.g. "\<player\>" transforms to "User1")
- **Metadata** that can be added to easily track version and names
- **Easy localization loading** by just giving the language and directory
- **Macros** that help check keys and checking if they exist from a defined default file
- A simple **VsCode extension** to help you manage ```.selp``` files
